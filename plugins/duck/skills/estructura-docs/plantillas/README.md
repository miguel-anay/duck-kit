# Documentación

Índice de la documentación del proyecto. Un enlace por documento, con una línea de qué responde.

## Producto y diseño

- [PRD](PRD.md): qué se construye y para quién.
- [TECH-DESIGN](TECH-DESIGN.md): cómo se construye.
- [adr/](adr/): decisiones de arquitectura, una por archivo.
- [specs/](specs/README.md): cada cambio, especificado antes de escribir código.

## Operación

- [SECURITY](SECURITY.md): amenazas y controles.
- [DEPLOY](DEPLOY.md): cómo se despliega y se revierte.
- [guias/](guias/README.md): ejecución local, entornos y flujo de trabajo.
- [manuales/](manuales/README.md): manual de usuario y manual técnico.

## Equipo e IA

- [convenciones/](convenciones/README.md): reglas del proyecto.
- [ia/](ia/README.md): contexto y agentes de IA del proyecto.
- [plantillas/](plantillas/): plantillas de spec y de agente.
- [odd/](odd/): documentos de tareas de ODD, si el proyecto los versiona.
- CHANGELOG: qué cambió en cada versión.
