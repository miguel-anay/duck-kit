# Guías

Cómo se trabaja en el día a día, paso a paso.

- **Ejecución local**: requisitos, cómo levantar cada repo y cómo correr las pruebas.
- **Entornos**: qué ambientes hay, qué variables necesita cada uno (sin valores secretos) y dónde se configuran.
- **Flujo de trabajo**: de la spec al merge (ramas, PR, revisión, cierre del ticket).
